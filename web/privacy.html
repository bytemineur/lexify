隐私政策 · Privacy Policy

不注册、不画像，只数有多少人看。

本站是一个公开的法律数据看板，没有注册、登录、付费或会员体系，因此我们不会拿到你的姓名、手机号、邮箱、身份证号等信息。本页说明我们实际收集了什么、怎么用、存多久，以及你可以怎么关掉。

一、适用范围与运营者

本政策适用于 lexify 的网页、接口与 AI 咨询功能，适用于所有访问者。本站由 lexify 的开发者运营，本政策中的「我们」指该运营者。

本政策不适用于你通过本站链接跳转到的第三方网站（例如政府采购平台、法院官网），它们的个人信息处理规则由其自行公示。

二、我们不收集什么

  • 不要求注册，不收集姓名、手机号、邮箱、身份证号、单位与执业信息；
  • 不收集精确地理位置、通讯录、相册、剪贴板、麦克风与摄像头数据；
  • 不投放广告，不做跨站追踪，不向广告平台共享数据；
  • 不建立用户画像，不把访问记录与任何真实身份关联。

三、我们收集哪些信息

为知道「哪些数据真的有人看、哪些页面需要优化」，本站记录匿名浏览事件，字段如下：

  • 页面与检索：页面路径、查询参数里的关键词、页面标题；
  • 来源：来源域名（从哪个站点跳转过来，或直接访问），并据此归类为直接访问 / 搜索引擎 / 外部链接 / 站内跳转；
  • 设备与环境：浏览器类型、操作系统、设备类型（桌面 / 手机 / 平板），来自浏览器自报的 User-Agent；
  • 时间与停留：访问时间、会话标识、页面停留时长（离开页面时由浏览器上报，属于估算值）；
  • IP 的哈希值：仅用于粗略统计独立来源与识别异常流量，见第七条；
  • AI 对话：你在「乐菲」里输入的问题与模型回复，仅在你提问时产生并实时转发给模型服务商。

四、收集方式与用途

浏览数据由页面里的一个轻量脚本自动上报，用于：统计页面热度与来源结构、判断哪些数据与筛选维度值得继续做、发现异常流量与滥用、排查故障。除此之外不做他用。

AI 对话内容仅用于生成当次回答，不用于训练模型，也不写入本站数据库。

五、我们不做的事

不共享、不转让、不公开披露你的浏览记录与 AI 对话；不出售数据；不做广告投放与再营销；不基于浏览行为做个性化推荐或定价。

仅在下列情形中，我们可能依法提供必要信息：与国家安全、国防安全直接相关；与公共安全、公共卫生、重大公共利益直接相关；与犯罪侦查、起诉、审判和执行直接相关；法律法规规定的其他情形。

六、Cookie 与本地存储

本站不设置第三方 Cookie，也不使用广告或统计类第三方脚本。浏览器里留下的本地存储只有两项：

  • localStorage：只存主题偏好等界面设置，不含身份信息；
  • sessionStorage：只存一个随机生成的会话标识，用于把同一标签页内的多次浏览算作一次访问；关闭标签页即失效。

你可以在浏览器设置里清除这些数据；清除后统计口径会略有变化，但不影响正常使用。

七、IP 地址怎么处理

服务器收到请求时会拿到你的 IP，但我们不保存原文：入库前统一做 sha256(盐 + IP) 计算，只保留前 16 位作为来源标识，盐值保存在服务端。

该哈希不可逆，无法还原出 IP 地址；它只用于「同一来源的访问次数」与「异常频率」这类聚合判断，不用于定位个人。

八、第三方服务

本站运行依赖以下第三方，它们只在必要范围内接触数据：

  • DeepSeek：AI 咨询的模型服务商。你提问时，问题文本与我们设定的系统提示会发送到其接口，处理完返回回答；本站不保存对话记录。其处理规则见该服务商的隐私政策。
  • GitHub：托管本站源代码与 issue 反馈。你在 issue 里主动公开的信息，按 GitHub 的规则处理。
  • 云服务器与带宽服务商：承载本站运行，可能接触访问日志（含 IP），但我们不在其中保存明文 IP。

九、存储期限与删除

浏览事件默认保留 180 天，超过期限由后台任务自动删除；你也可以在配置里调整保留天数。汇总统计（如某页的总浏览量）可能长期保留，但不含任何可关联到个人的字段。

AI 对话不落盘，服务端没有可删除的历史记录。

十、我们如何保护信息

站点全站 HTTPS 传输；收集字段按最小必要设计；IP 加盐哈希；后台管理入口需要口令并默认只允许本机访问；对明显异常的访问做频率限制与来源封禁。

需要说明的是：任何系统都无法保证绝对安全。若你发现本站存在安全问题，欢迎通过第十五条的方式告诉我们，我们会尽快修复。

十一、安全事件的通知

若发生个人信息泄露、损毁或丢失等安全事件，我们会立即评估影响、采取补救措施，并按法律法规要求告知你可能受到的影响、我们已采取的措施，以及你可以自行采取的防范建议。

十二、你的选择与权利

  • 拒绝统计：浏览器开启「请勿追踪（DNT）」后，本站不再记录浏览事件；也可以在任意页面地址后加 ?notrack=1 单次关闭；
  • 清除本地数据：清除浏览器本地存储即可清掉会话标识与界面偏好；
  • 查询与删除：由于浏览记录不与身份关联，我们通常无法定位「你的」具体记录；若你能提供足以定位的信息，我们会在核实后处理。

十三、未成年人

本站面向成年人与法律从业者。若你未满 18 周岁，请在监护人指导下阅读本政策并使用本站；监护人对其个人信息有疑问的，可通过第十五条联系我们。

十四、政策更新

本政策可能随功能调整而更新，更新后的版本在本页发布并标注版本号与生效日期。涉及收集范围或使用目的的重大变更，我们会在站点显著位置提示。

十五、联系我们

对本政策有疑问、建议或投诉，可通过项目仓库的 issue 反馈：github.com/bytemineur/lexify/issues。涉及数据删除或更正的请求，请说明具体页面与时间范围，我们核实后处理。

一句话总结：我们不认识你，也不想认识你；只统计「哪一页有人看」，IP 只留不可逆的哈希，180 天后自动清掉。
