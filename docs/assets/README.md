# 设计资源归档

放这里的是**网站的视觉素材**，方便以后改版、做 PPT、印名片时直接取用。

## 目录

| 目录 | 内容 | 线上是否在用 |
|---|---|---|
| `brand/` | lexify 字标：SVG 双色（蓝 / 白）+ PNG 三档 | ❌ 不在页面里用，纯素材 |
| `favicon/` | 站点图标 32 / 64 px | ✅ 线上用的是 `web/favicon-*.png`，这里是副本 |
| `svg/` | `field.svg`——首屏「帘子」的静态底图（无 JS 时的兜底） | ✅ 线上用的是 `web/field.svg`，这里是副本 |

> **为什么有副本**：`web/` 里那份是站点运行时真正加载的，部署时只拷 `web/` 也能完整跑。
> 这里的副本是为了「万一 web/ 被改坏了，还有原稿」，改动时请两边同步。

## 字标怎么重新生成

字标是 Playfair Display 700 的 `lexify`，SVG 里以 base64 内嵌了字体（所以是**真矢量**，
任何环境都能正确渲染，不依赖用户装字体）。要改颜色或重排：

```bash
# 蓝色 → 改 fill="#1434CB"；白色 → fill="#FFFFFF"
# 字体文件在 web/fonts/PlayfairDisplay-700.woff2
```

PNG 是从 SVG 渲染的，需要时用浏览器打开 SVG 再导出，或：

```python
# 任意 SVG → PNG（无损）
# 用 Chrome headless 或 Inkscape 都行
```
